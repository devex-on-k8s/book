# Platform

This project is part of the Min Salus system and provides the automated scripts to set up a Kubernetes platform in a local environment. It's part of the project built in the [Developer Experience on Kubernetes](https://www.manning.com/books/developer-experience-on-kubernetes) book by [Mauricio Salatino](https://salaboy.com) and [Thomas Vitale](https://www.thomasvitale.com).

## Activate Environment

With Devbox:

```shell script
devbox shell
```

## Create Cluster

```shell script
./create-cluster.sh
```

## Destroy Cluster

```shell script
./destroy-cluster.sh
```
